  • 生成 candidate_gaps

8 gap_verify ★

唯一 Agent
  • Tool-Calling 验证

L3 Tool-Calling Agent · 工具箱 · ToolRuntime
verify_agent / tool_runtime

Gap Verify Agent（唯一 ReAct 循环）

verify_agent.py · ChatOpenAI.bind_tools
  • 输入：topic + candidate_gap + paper_cards + memory + critiques
  • 循环：LLM 决策 → tool_calls → ToolMessage → 再决策
  • 输出判决：KEEP / REFINED / REJECTED
  • 执行终止（另一维度）：COMPLETED / BUDGET_EXCEEDED / INSUFFICIENT_EVIDENCE / TOOL_FAILURE
  • Prompt 分区：System / User / UNTRUSTED_EVIDENCE（论文不可覆盖指令）
  • 未充分验证时仍可 KEEP，但报告必须写清「验证未完成」
模型
默认 qwen-plus（DashScope OpenAI 兼容）
轮次上限
GAP_VERIFY_TOOL_ROUNDS ∩ GAP_AGENT_RECURSION_CAP（默认≤12）

ToolRuntime = 工具安全执行器

不是业务 Tool 本身；不自动换数据源
  • 门禁：工具白名单、max_tool_calls、动作签名去重（visited_actions）
  • 超时：ThreadPoolExecutor + GAP_TOOL_TIMEOUT_S（默认 30s）
  • 重试：timeout/429/transient → 指数退避 (2^n)*0.25 + jitter
  • Empty：HTTP 成功但 0 结果 → status=empty，累计 empty_streak
  • Trace：每次 attempt 一条（trace_id、args、duration、status、retry_index、result_summary…）
  • 不负责：Ask User（在 planner）、换 OpenAlex→S2（在 AcademicSearchService）

工具箱 Toolbox（进程内 @tool 白名单 · 非 MCP）

检索
  • search_papers → AcademicSearch；内部可有限 Query Rewrite（预算 2）
  • retrieve_rag → PaperRAG Top-K 证据块
  • recall_memory → ResearchMemory + REJECTED 原因
引用证据链
  • find_citing_papers → 后续引用/相关工作
  • get_citation_context → 引用语境批评类型
  • read_fulltext_section → limitations/method 等已索引章节
返回给模型的形态
  • 一律 JSON 字符串瘦身结果（标题/片段/count）
  • 不把全文 PDF / 大向量写进 Trace
  • 失败时 ToolMessage 带 error_type / retryable / suggested_action 标签
L4 能力服务层（节点与工具共同调用）
services / gap_discovery/*

AcademicSearchService

  • 入口：sanitize_academic_query
  • 主路径：OpenAlex / Semantic Scholar（可互备）
  • 单源有限 retry；双源失败或空 → seed_corpus
  • FORCE_SEED_CORPUS 可强制离线演示
  • 返回：results + backend + notices

CitationService + fulltext

  • 找 citing / related papers（年龄感知预算）
  • 从 citing 全文抽 citation context
  • 批评类型：CRITIQUE 等；不可用则不编造
  • OA PDF 下载 + pypdf 章节（limitations/method…）
  • 无付费墙破解

PaperRAG + ContextBuilder

  • 索引：PaperCard 文本块 + Memory 条目
  • 向量：DashScope Embedding → Chroma
  • 失败：Lexical 词面余弦 Top-K
  • ContextBuilder：为 gap 拼验证上下文
  • 空命中不自动联网（可由 Agent 再调 search）

ResearchMemoryStore 等

  • 长期记忆（跨 run），按规范化 topic
  • Gap 与 REJECTED 词面/可选向量去重
  • query 按 topic 保留最新 N 条（默认 40）
  • relevance：中文主题→英文学术 query
  • evolution：演进边 + limitation lifecycle
L5 存储与持久化（每库存什么 · 详细）
Chroma / SQLite×3

① Chroma · RAG 向量库

路径：workspace/chroma_papers · collection 默认 paper_cards
  • 存什么（每条 chunk）
    • id：chunk_id
    • document：文本块（≤约 4000 字入库）
    • embedding：DashScope 向量
    • metadata：paper_id、title、year、section（如 limitations）
  • 文本从哪来：PaperCard 摘要/局限/章节片段；Memory 条目也可入库
  • 检索返回：score、paper_id、title、section、year、text 摘要、backend=chroma|lexical
  • Fallback：Embedding/Chroma 失败 → 内存 LexicalIndex（token 余弦）
  • 注意：默认可在 init 清空 session collection（本轮任务新鲜索引），不是跨任务永久文献湖

② SQLite · research_memory.db

长期研究记忆（与 tasks 库表级隔离）
  • 表 papers：paper_id、topic、title、year、payload(JSON)、updated_at
  • 表 gaps：gap_id、topic、description、status（KEEP/REFINED/REJECTED）、reason、payload、updated_at
  • 表 queries：topic、query、purpose（landscape/verify/…）、created_at；按 topic 裁剪最新 N 条
  • 表 artifacts：topic、kind、key、payload（各类工件快照）
  • 召回：exact topic；REJECTED+reason 优先给 planner/discover/verify
  • 去重：新 Gap vs 历史 REJECTED（词面相似 + 可选 embedding）

③ SQLite · research_tasks.db

任务 / 业务 Checkpoint / 事件 / 幂等
  • research_tasks：task_id、thread_id、topic、status、current_node、termination_reason、时间戳
  • task_checkpoints：checkpoint_id、node_name、state_json=完整 ResearchState
  • task_events：seq + event_json（可重放 SSE）
  • side_effect_log：幂等键（如 save_gap / save_query）防 Resume 重复写
  • Resume：latest checkpoint → 按 completed_nodes 跳过已完成节点

④ SQLite · langgraph_checkpoints.db

官方 SqliteSaver（checkpointer.py）
  • 在 graph.compile(checkpointer=…) 接入
  • 真正写入主要在 compiled.invoke(..., thread_id)
  • SSE/iter_pipeline 演示主路径不依赖它做 Resume
  • thread_id = Checkpoint 命名空间，与 task_id 默认常相同但语义不同

⑤ ResearchState 内存黑板（会进 Checkpoint）

一次 run 的工作记忆
  • 身份：task_id、thread_id、current_node、completed_nodes
  • 文献：papers、paper_cards、rag_hits
  • 分析：analysis、limitations、evolution_chain、critiques
  • Gap：candidate_gaps、verified_gaps、gap_verification_results
  • 控制：tool_call_count、verification_round、visited_actions、tool_traces、warnings、termination_reason…

⑥ PaperCard 里有什么（进 RAG 前的结构化文献）

models.py · 存在 State，也可落 Memory payload
  • paper_id / title / year / abstract / url / doi
  • methods、claimed_contributions、limitations
  • evidence_refs（章节引用片段）
  • fulltext_status：FULLTEXT | ABSTRACT_ONLY | FAILED
  • 这是 Reader 的核心产物，Analyzer / RAG / Verify 都依赖它
L6 执行预算 · 安全 · 可观测 · 失败策略
横切能力

Budget

  • verification_round：验几个候选 Gap
  • Agent 内 LLM 轮次上限
  • max_tool_calls + visited 去重
  • 单工具 timeout / 任务 deadline（默认 900s）
  • empty_streak；可选 token_budget（依赖 usage_metadata）

Safety

  • System / User / Untrusted Evidence 分区
  • 工具白名单；文档不能改预算
  • injection 短语写入 warnings
  • 报告前校验 paper_id/标题是否在证据集
  • 剥离「全球首次 / 已证明创新」措辞

Observability

  • tool_traces → State → Checkpoint
  • SSE state_patch / tool_* / checkpoint_saved
  • 前端 TaskObservability 时间线
  • evals/ 离线硬规则评测基线

失败策略分层

  • Runtime：异常分类 → retry（jitter）
  • search_papers：Query rewrite（有预算）
  • AcademicSearch：换源 + Seed fallback
  • Planner：ask_user（NEEDS_USER_INPUT）
  • Budget/权限/死循环：stop + 保留已有证据
L7 最底层外部 API / 模型 / 本地引擎
Foundation

大语言模型

  • 默认：通义 Qwen（qwen-plus）
  • 协议：OpenAI Compatible
  • 网关：DashScope compatible-mode
  • 也可配 Ollama / LM Studio
  • 用途：Planner / Analyzer / Verify / Report

Embedding

  • DashScope Embedding API
  • 供 Chroma 入库与查询
  • Memory Gap 去重可选用
  • 失败 → Lexical，不阻断主流程

学术检索 API

  • OpenAlex Works
  • Semantic Scholar Graph
  • 本地 seed_corpus 兜底
  • 可选 S2 API Key 提高限额

全文与解析

  • OA PDF HTTP 下载
  • pypdf 解析
  • 章节：limitations / method…
  • 失败则 ABSTRACT_ONLY

本地存储引擎

  • Chroma PersistentClient
  • SQLite × 3 库文件
  • 未使用：MCP Server/Client
  • 未使用：Skill Registry
  • 网页搜索非主源（可配置但非演示主路径）
