①b 共享状态 + CheckpointState/CKPT

ResearchState（活黑板）

  • 一次任务内存字典；节点只改自己字段
  • 身份：task_id · thread_id · current_node · completed_nodes
  • 文献：papers → paper_cards → analysis/limitations → evolution/critiques
  • Gap：candidate → verified · results · final_report
  • 控制：tool_call_count · round · traces · warnings · termination · status
  • 不放：DB连接、模型客户端、PDF二进制
节点改 State → SSE推摘要 → 下一节点读最新 State

Checkpoint（黑板拍照）

  • 业务主路径：每节点完成 → research_tasks 写完整 state_json
  • 附带 node_name、completed_nodes、task status
  • Resume：读 latest → 灌回 State → 跳过已完成节点
  • events 可重放 SSE；side_effect_log 防重复写 Gap/Query
  • LangGraph SqliteSaver 另库，主要用于 invoke；流式恢复靠业务 CKPT
Node done → save_checkpoint → 崩溃后 Resume → completed_nodes 跳过

④b PaperRAG · 只服务 Gap 取证（非通用问答）rag.py
PaperCard/全文/memory→ 切块→ Embed+Chroma∥ Lexical→ Top-K→ ContextBuilder

入库（gap_verify 前）

  • 每 PaperCard → abstract / method / problem / limitations
  • OA 全文块 add_fulltext_chunks（section=章节）
  • 本轮 research_memory 也灌入（section=memory）
  • meta：paper_id · title · year · section；文≤4k
  • 默认 CHROMA_CLEAR_ON_INIT：本轮会话索引

双后端

  • 主：Chroma + DashScope embed（cosine）
  • 备：内存 Lexical（token 余弦）
  • 块同时写两路；Chroma 空/失败 → Lexical

检索 · retrieve_rag

  • query = gap 描述 + verification_queries
  • Top-K；可按 section 过滤 retrieve_section
  • 空命中不自动联网（再搜走 search_papers）
  • hit：score · section · title · text[:800]

ContextBuilder

  • gather → select → structure → compress
  • 拼：Gap · 相关 PaperCard · RAG hits · Memory · 新搜
  • 超 max_chars≈6k 截断；喂单次 LLM
目的：verify Agent 用库内证据判决 KEEP/REFINED/REJECTED · 不是聊天知识库
